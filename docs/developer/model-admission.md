# 网关模型准入（#417）

- 需要选择渠道的请求先检查站点目录，再检查分组和选择渠道。站点目录由匿名模型广场（定价结果与站点 `UserUsableGroups` 的交集，保留 `all` 语义）及模型管理中未删除的条目组成，不按当前用户或令牌分组裁剪。仅向特定用户分组可见的模型若要准入，须在模型管理中收录；展示状态不影响准入，精确、前缀、后缀和包含规则仍有效。
- 模型广场会自动发布符合既有定价逻辑的已启用 ability，因此没有手填元数据不等于没上广场。单有渠道的 `models` 字段、渠道映射目标、未发布的 ability 或令牌白名单，不构成收录。展示状态和分组路由能力互不替代。
- 先用 `FormatMatchingModelName` 归一化进行目录匹配，同时保留原名兼容精确配置和现有路由；不把请求名改写成目录键。路径模型使用现有解析结果。
- 未收录模型返回 HTTP 404、`model_not_found`，不进入选渠、上游或计费，不写使用日志和错误日志。目录不可用时返回 503，不误报为未收录。空模型保持 400；已收录但无可用渠道继续使用现有错误和日志。查询历史任务、已有任务重混等不需要选渠的入口不经过此准入。
- Default 与 Classic 共用该后端契约，已有 `/api/pricing` 和模型管理界面不变。聚焦测试使用合成配置及内存 SQLite，覆盖 JSON、Gemini 路径、归一化、隐藏模型和日志边界。
- 实时入口在 WebSocket 升级前检查；异步图片任务在入队前检查，重放分发时按当前目录重新检查。原有任务查询不受后来下架影响。
