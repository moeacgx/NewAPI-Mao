# .369 Canvas 图片请求分组隔离发布

## 版本范围

版本 `v1.0.0-rc.10.1.10.369` 基于 `custom-main`，本次修复：

- Canvas 内部 `group` 不再进入上游 JSON 或 multipart 正文，避免 Gemini 兼容
  图片渠道拒绝请求；转换和请求体透传模式均适用。
- 同步及异步请求在渠道分发前，根据可信上下文复查分组权限，避免审核等待或重放
  期间撤权后仍调用上游。保留原分组选择、提示词审核及计费语义。

修复与测试记录见 [Canvas 分组参数与上游请求隔离](14_canvas_group_request_boundary.md)。
Default、Classic 共用该后端行为，无前端界面、认证配置、数据库或依赖变更。

相比 `.368`，主分支还已合并以下内容，本版一并包含：

- PR #395：图片任务跨域、鉴权和内容归属的回归测试及排查文档，未改生产 CORS 实现。
- PR #396：Default 单密钥转多密钥渠道及分组标签能力，包含对应测试和七语言文案；
  其能力与验收边界见已有 Default 正式基线集成交付文档。
- 已合并的部署记录和开发文档更新。

## 发布与验证

本地针对实际修改完成回归与独立审查后创建 PR，合并至 `custom-main`，
再对合并提交打版本标签。标签触发仓库已有 Linux 双架构二进制、
校验和及 GHCR 多架构镜像发布工作流。

本次发布不包含生产部署；真实 Gemini 图片结果仍需服务更新后验收。
最终 PR、测试结果、工作流和资产校验结果记录于 GitHub Release。

## 共享契约与分享评估

Canvas 客户端继续用 URL `group` 与 Cookie 登录态；请求结果格式、任务查询、
模型 ID 和费用字段不变。普通令牌 API 不经过 Canvas 正文清理。

NewAPIForDouDi、NewAPIModifyByGang 均建议先核对是否沿用相同 Canvas
分组注入与重放链路；存在相同实现时值得同步过滤和权限复查，不建议盲目复制。
本次不发送跨仓通知。
