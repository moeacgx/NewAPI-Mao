# 上游模型校验白名单直接填写渠道 ID

## 目标与范围

当前 maolaoapi 外置模块仍是 0.1.0，因此没有已在宿主和模块 0.2.0 实现的白名单界面。
本次准备 0.2.1，在 Default 和 Classic 的同一白名单区增加渠道 ID 文本输入，允许逗号、中文逗号、分号、空白或换行分隔。
输入与已有勾选、移除同步；有效正整数去重，最多 1000 个。非法输入阻止保存，不静默丢弃。
空文本清空白名单；新填 ID 在保存时由宿主验证存在性，已有已删除渠道仍按原约定可移除。

## 契约与安全边界

继续通过原 `PUT /api/extensions/upstream-model-guard/config` 的 `excluded_channel_ids` 保存，沿用 `expected_version` 并发保护、Root 权限和宿主全部跳过语义，不新增接口、权限或数据库迁移。
白名单渠道跳过本插件检测、计数、记录、关渠及通知。其余分组规则、检测开关和容错阈值保持原行为。
外置模块版本独立于宿主，主程序升级不会自动替换已安装模块；安装须保留原启用状态并逐节点刷新。

源码与构建入口同时维护主仓库快照和独立扩展仓库，已有 0.2.0 包不可覆盖。提供新的 0.2.1 安装包及校验值；发布和线上安装状态以实际执行结果为准。

## 验证计划

双模板分别覆盖混合分隔符、重复值、非法 ID、数量上限、输入与勾选同步、清空、保存失败保留草稿和回显。
运行既有白名单/配置回归、原生入口构建、语言资源完整性、ZIP 内容与历史版本不可变校验。
