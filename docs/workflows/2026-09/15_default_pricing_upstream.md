# Default 上游价格与日志筛选修复

## 目标与范围

基于 `origin/custom-main@45ab82100`，仅处理 Default（`web/src`）前端。Classic 不在范围内。

## 实施计划

1. 先新增失败回归，再逐段移植 `ac381acf4` 同日与跨午夜范围修复；保留合法比较边界并保持可视化往返稳定。
2. 价格使用现有计费货币格式化函数，避免 Tokens 额度模式污染价格单位；保留规格路线价格、零分组倍率、充值折扣。
3. 日志筛选恢复文本输入，通过样式控制视觉遮蔽，避免被浏览器识别为密码框。

## 契约与边界

- 日志 `request_rules` 仍是命中状态与倍率的权威来源，未知条件保留原文。
- 保留 `img_o`、`model_price_variants`、`model_route_price_variants`、分组显示名及上游模型权限。
- 不增加后端接口、变量、计费函数或存储字段，不迁移任务插件及新审计 API。
- 编辑器文案及七种语言由主集成工作项统一维护。

## 验证计划

先运行新增失败回归，修复后运行受影响测试及既有价格契约测试。每批最多 60 秒。集成阶段执行 Bun lint、typecheck、test、build，并校验 Markdown 与 Git 差异。

## 验证结果

- 先运行失败回归：同日和相同边界仍使用 `||`、混合条件未合并均被稳定复现；Tokens 模式下 `$4` 被显示为 `2000000`。
- 复核上游补丁时额外复现并修复两类风险：不一致的运算符不能按范围方向重写；`hour < 24` 等合法排他上界不能被丢弃。最终时间规则 13 项测试通过；撤销上游仅按函数返回值域限制比较边界的实现。
- 日志交互失败回归确认隐藏后字段变为 `type=password`；修复后保持 `type=text`，遮蔽切换不改变输入值，按 Enter 仍提交原内部分组、令牌及用户名。
- Bun 受影响测试与既有价格契约测试：4 文件、26 用例通过。
- `bun run typecheck` 和 `bun run build` 通过。
- 6 个变更 TS/TSX 文件定向 lint 无错误；完整 `bun run lint` 因既有 Default 与 Classic 错误失败，包括未改动的 `setup-wizard.tsx`、`rankings/index.tsx` 和 Classic Hooks。
- 使用仓库 oxfmt 配置格式化本工作项文件，保留原版权头；`git diff --check` 通过。
