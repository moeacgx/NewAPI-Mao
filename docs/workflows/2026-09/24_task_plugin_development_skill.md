# 任务插件开发技能提炼

## 目标与范围

根据 Jev 连续出现的路由、模型别名、响应包裹和 Token 统计遗漏，建立仓库级
`.agents/skills/task-plugin-development/`，覆盖新插件、官方同步、宿主兼容与问题修复。
本项只增加开发规范和技能，不修改主程序、现有插件、价格、生产配置或两个现有修复 PR。

## 来源与方案

2026-09-24 核对官方插件仓库固定提交 `b42cc99a6bd1998d0cc1581270bd46798ce00ad6`，
参考 TypeSafe、Alibaba、Doubao、Sora、Kling、SunoAPI、Google、Vertex AI 共八类插件，
以及官方 API v1、类型声明、索引规范和仓库发布规则。
本地主分支基线 `b6476c6c8c6fcc5c3b7725545fb3b16ba117a625`；
本地 Token 修复仍为 PR #270，配套 Cloudflare 插件修复仍为 PR #7，不能写成已上线能力。

技能采用入口、官方模式参考、按任务选择的验收矩阵三层结构。
在 AGENTS.md 增加准确触发入口，并从开发文档索引及插件专题链接，避免仅存文件而无人使用。
遵守源仓库差异：官方禁止仓库内插件测试，本地插件仓库允许测试；官方不可变版本和索引生成规则
不能与本地 retired 索引、目录布局混淆。官方示例仍需要实际宿主验证，不能直接当作正确答案。
