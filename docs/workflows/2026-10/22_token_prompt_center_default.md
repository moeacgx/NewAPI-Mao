# Default 提示词中心与令牌技能徽标

## 范围

仅负责 `web/src` Default 模板；Classic 由独立工作项实现。路由为 `/prompt-center`，
侧栏入口使用独立的 `console.prompt_center` 配置。令牌名称旁使用「技能 · 数量」徽标；无安装隐藏，
全部安装项停用或下架时灰显，鼠标及键盘可打开安装管理弹窗。

## 实现与契约

- 用户浏览启用模板、阅读纯文本详情，按名称检索和分页选择自己的令牌。
- 安装、顺序调整、停用和卸载先写入弹窗草稿；保存时完整替换安装列表。
- 管理员按角色显示模板编辑入口，支持创建、编辑、上下架、排序和分组白名单。
- 白名单显示当前 `group_details.name`，保存稳定 `group_ids`。上架必须选择实体分组；下架草稿可以为空。已失效分组在编辑器中保留可移除选项。
- 管理员更新携带原始 `version`；服务端并发冲突时保留编辑草稿。
- Markdown / SKILL.md 在浏览器按文本读取，不执行脚本、附件和工具。
- 正文使用普通文本展示，避免将模板内容作为 HTML 执行。令牌选择与保存不访问密钥读取接口。
- 模板正文最大 32768 UTF-8 字节，每令牌最多 8 项，启用正文合计不超过 65536 字节。
- 安装列表加载失败不展示保存按钮，避免把失败响应当作空列表覆盖服务端。
- 保存失败保留草稿；成功刷新令牌计数和安装查询。后台查询更新不重置正在编辑的安装草稿。
- 新增文案覆盖 en、zh、zh-TW、fr、ru、ja、vi，动态错误键纳入静态提取列表。

接口遵循 [令牌提示词中心](../../developer/token-prompt-center.md)。前端不改变令牌额度、
密钥和实际分组权限。非白名单请求是否装载由后端运行时判定，徽标仅说明安装状态。
