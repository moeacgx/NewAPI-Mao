# .355 网关 Skills 与提示词中心整合发布

## 目标与范围

将 `custom-main` 自 `.354` 发布标签之后的已合并改动发布为
`v1.0.0-rc.10.1.10.355`。本次完整提交范围以该标签与最终发布提交的差异为准，主要包含：

- #328 修复 Default 任务日志请求路由 404。
- #337 将工单通知合并为用户新建/追加回复事件；停用管理员回复及状态变更通知，并迁移历史通知任务。
- #338 在 Default 与 Classic 使用日志展示技能使用状态与发现轮次。
- #336、#339 恢复损坏译文并稳定前端回归测试。
- #340 修复 Responses 网关 Skills 发现阶段遇到未识别客户端工具调用时返回 502。
- #341 支持将技能模板授权为“不限分组”，但仍要求实际请求分组已启用。
- #342 支持管理员按分类版本删除分类，并在事务内把其中模板移到“未分类”。

本轮新增的 Skills 与提示词中心接口不改变客户端请求格式、密钥、模型 ID 或计费字段。
Responses 安全回退可能结束可选 Skills 发现并恢复原请求；发生时不会伪造技能正文或使用徽标，
消费记录以 `gateway_skills.discovery_fallback` 标记。用户反馈关闭网关 Skills 后 Responses
请求恢复，与 #340 记录的故障症状一致；本次发布不修改现有网关 Skills 配置开关。

## 数据迁移与兼容边界

- 唯一新增数据库列为 `prompt_templates.all_groups`，可空且无数据库默认值。
  存量 `NULL` 与 `false` 等价，继续按原白名单授权；仅显式 `true` 且实际分组启用时开放安装与装载。
- `prompt_templates.repository_source_json` 已由 `.354` 新增，本次不重复迁移。
- 工单通知迁移可重复执行：合并旧的新建/用户追问任务并更新旧默认模板，保留自定义模板；
  停用旧管理员回复和状态变更任务但保留记录。若同时订阅旧新建与追问事件，部署后需在通知中心删除一个合并事件重复任务。
- 迁移过程中旧节点不认识新通知事件；混合版本期间可能漏发工单通知。若生产无相关通知任务，迁移只会执行空更新。
- `.354` 节点忽略新增 `all_groups` 列且继续按白名单处理，失败关闭；滚动期间不要创建不限分组模板，
  也不要删除分类或编辑引用该分类的模板。全部节点升级后再使用新管理功能。
- 回滚到 `.354` 不删除新增列。不限分组模板在旧版按白名单处理而无法装载；新工单通知事件需按旧事件重新建任务。
  分类删除属于数据变更，应用回滚不会恢复已删分类；不得用整库回滚覆盖线上新数据。

## 发布门禁

1. 版本准备 PR 合入 `custom-main`，合并前 PR 检查通过，合并后确认版本文件与工作区干净。
2. 在准确的发布提交创建附注标签 `v1.0.0-rc.10.1.10.355`，不移动已有标签。
3. 等待 Linux Release 与 Docker 多架构工作流成功；核对 amd64/arm64 资产校验和、镜像架构、
   OCI version/revision 与标签提交完全一致后再将 Release 设为 Latest。
4. 发布产物验证后才可更新生产。正式站使用 GHCR 固定 digest，不使用浮动 `latest`。

## 验证计划

- PR CI 验证 Go vet/build/test、Default 类型检查和测试；Classic 双模板交互测试与构建由其合并 PR 和发布构建补充。
- 本地及 CI 单次 Go 测试设置 60 秒超时；独立检查 `relaykit` 是否保持独立构建。
- 发布前确认 `VERSION`、PR 合并提交、tag peeled SHA、Release 资产摘要与两架构 manifest。
- 不调用收费模型做自动部署验收；真实 Responses/Skills 用户请求仍由实际启用该设置的用户验证。

## 共享契约与跨项目评估

- Responses 的内部技能发现遇到不识别的客户端工具后可安全结束发现并恢复正式请求；回退不执行该工具，
  也不保证本轮已读取技能正文。该修复只影响网关 Skills 启用的请求路径，普通请求契约不变。
- 技能 `all_groups` 是管理与授权能力；其对外仍使用既有请求密钥、模型 ID 和计费格式。
  工单通知合并属于管理通知语义，不影响模型接入方。
- NewAPIForDouDi、NewAPIModifyByGang：可评估 Responses 安全回退、技能授权编辑和使用日志徽标；
  本次未检查目标实现，不能断言目标缺少这些能力或可直接移植。
