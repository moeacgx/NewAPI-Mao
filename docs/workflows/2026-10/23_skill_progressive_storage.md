# 渐进式技能存储与导入

## 目标与边界

2026-10-23：新增 `load_mode=progressive`，技能目录、主正文和引用文本分别保存。
旧空值及 `eager` 继续全文装载，保留 32768 / 65536 字节限制。
渐进式合集不生成拼接正文，最多 128 个技能；单文件 8 MiB、包内文本 64 MiB。
ZIP 压缩数据最多 16 MiB，最多 4096 个条目，所有条目声明解压总量最多 64 MiB。
只接收技能根目录内支持的文本资料，不执行脚本或访问包外资源。

## 数据与接口契约

`PromptSkill` 包含稳定 `id`、标题、说明、包内主文件路径、正文和资源数组。
资源使用相对于技能根目录的路径，不接受绝对路径、反斜杠、越界路径或特殊文件。
主文件路径保留包内位置，可为空并由服务端生成；资源不能使用大小写任意的 `SKILL.md`。
标题最多 80 字符，说明最多 512 字符；发布渐进式模板时，每个技能均须具备用途说明。
模板及文件文本拒绝 NUL，兼容 PostgreSQL TEXT；路径最多 1024 字节。
渐进式元数据独立保存；文件元数据和 48 KiB UTF-8 分块保存在新增普通表，
避免 MySQL TEXT 单列上限，迁移不改写旧正文。旧程序不会将渐进式正文误作完整提示词。

新增表为 `prompt_skill_records`、`prompt_skill_files`、`prompt_skill_chunks`。
文件路径使用 SHA256 作为索引标识，避免 MySQL 旧索引字节限制；正文不进入元数据表。
保存模板、替换文件及版本递增位于同一事务，失败时原正文、引用文件和版本均保留。
技能 ID 全局唯一，拒绝把其他模板中的 ID 移入当前模板；同包内重排保持身份。
切回全文模式时清理三张新表中该模板所属内容；全文合集不保存技能 ID、路径或引用资料。
全文合集还检查 JSON 转义后的旧 `skills_json` 不超过 TEXT 上限，超限建议改用渐进式模式。
现有管理 API 只提供下架，不提供物理删除：下架保留资料以便重新编辑，但立即拒绝后续读取；
卸载或删除令牌只撤销安装，不删除管理员拥有的模板资料。

`GetActiveTokenSkills` 只返回当前实际分组命中的已发布、已安装且启用技能元数据。
`ReadActiveTokenSkillFile` 每次重新验证安装、分组、发布状态和版本，按 UTF-8 字节分页；
空路径或 `SKILL.md` 读取主正文，返回引用路径目录。每页最多 24 KiB。
该上限针对 `Content`；`Resources` 是供网关内部使用的完整路径目录，运行时另做目录分页与预算。
分页起点若落在 UTF-8 字符中间则拒绝，终点收拢至字符边界，禁止损坏中文。
管理员接口返回完整编辑数据；普通用户摘要不提供正文和引用资料内容。
`GET /api/prompt-center/` 与 `GET /api/token/:id/prompts` 使用单独的摘要查询，
渐进式包仅查元数据表，不读取文件元数据或正文分块，避免浏览目录时加载整个包。
`POST /api/prompt-center/admin/` 和 `PUT /api/prompt-center/admin/:id` 的 JSON 读取上限为
448 MiB，以容纳单项镜像字段
和 Unicode 转义膨胀；实际正文总量仍在模型层按 8 / 64 MiB 校验，不能靠编码绕过。

ZIP、公开 GitHub 仓库和内置/在线商店导入均默认生成未发布的渐进式草稿，需管理员保存。
有标准 `SKILL.md` 时只将这些文件作为独立技能入口；根目录 README 不作为额外技能。
技能根目录内的 Markdown、TXT、JSON、YAML、CSV、TSV、XML、RST、TOML、INI、CFG、
HTML、HTM 和 TEX 保留为引用文本。最深技能根目录拥有对应文件，父技能不能获得嵌套技能内容。
脚本和二进制附件不导入；ZIP 仍将忽略条目的声明解压大小计入 64 MiB 防解压炸弹预算。
公开仓库固定到已解析提交读取；在线商店引用资料与主文件一样校验清单 SHA256。

## 验证计划

- 超过 32 KiB 的中文主文件、超过 64 KiB 的合集保存和重载完整一致。
- 保存、修改、重排保持技能稳定 ID，跨模板 ID 冒用被拒绝。
- 旧全文模板继续原限制；渐进式安装不占用旧正文额度。
- 别名分组、不同显示名称、停用、卸载、下架、过期版本及路径越界验证。
- ZIP、仓库和内置商店默认按需模式，保留说明与引用文件；脚本不导入。
- Go 测试使用 `-timeout=60s`；三库采用兼容 GORM 表结构，真实 MySQL/PostgreSQL 验收另记。

## 本地验证

`go test ./model ./service ./controller -count=1 -timeout=60s` 已通过：
model 33.256 秒、service 24.747 秒、controller 4.720 秒。
SQLite 实际验证大中文正文/引用资料重载、UTF-8 分页、稳定 ID、保存回滚、
模式转换清理、实际分组及历史别名、撤销/过期/下架、目录不读正文、公开 API 不泄露正文，
以及 ZIP、公开仓库模拟响应、在线商店资源校验。
最后兼容性审查将分组状态查询改为 GORM 子查询，避免 MySQL 8 `GROUPS` 保留字；
相关定向测试再次通过（model 4.580 秒、service 2.968 秒、controller 1.568 秒）。

数据库结构和查询按三库兼容规则审查，未连接真实 MySQL/PostgreSQL；
仓库/商店测试使用固定本地 HTTP 模拟，不代表已访问真实私有仓库或供应商。
