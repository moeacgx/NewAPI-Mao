# 云端技能目录查询结果传递

## 问题与目标

用户在操练场选用安装了渐进式技能的 API 令牌，询问“有哪些网关云端 Skills”时，
正式回答仍可能声称没有技能查询工具。私有发现阶段虽然持有目录和 `newapi_skills_list`，
正式生成此前只接收已读取的文件页，目录查询结果被丢弃。

本次让实际执行过的目录查询结果进入正式生成，支持按名称、用途、包名搜索与分页。
Classic、Default 操练场及四类外部 HTTP 对话接口共用后端链路，不修改页面布局。

## 方案与边界

- 私有阶段收到技能目录问题时，调用 `newapi_skills_list`；仅查询目录不读取技能正文。
- 会话只保存成功查询的参数并去重。正式生成前按当前令牌、实际分组、安装状态、发布状态及
  本轮版本重新生成目录结果，不能沿用已经撤权或改版的元数据。
- 传递名称、用途、技能 ID、包名、版本及查询分页信息，不传正文和引用文件。
  合并后的目录 JSON 最多 64 KiB，超出时明确标记 `truncated=true`；单页仍最多 32 项、32 KiB。
- 正式生成保留原始客户端工具及输出格式，目录作为有边界的数据上下文；不向外部 Agent
  声称它可以直接调用网关私有工具。未执行目录查询的请求不额外装载目录。
- 目录只表示当前请求分组允许使用的已安装技能，不代表站点商店中的全部技能。
  仅列举目录不显示“已使用 Skills”徽标或尾标；实际文件读取仍沿用既有使用标识。
- 不改数据库、认证、白名单和计费规则；额外上下文沿用正式请求输入估算与结算。
