# Classic 渐进式技能管理

## 目标与范围

本项只修改 `web/classic`。Default 页面与网关、存储由同一工作项分别实现。
沿用当前提示词中心浅蓝卡片布局，不重做视觉；普通用户只能查看摘要、安装和卸载。

## 数据契约与兼容性

- 旧模板缺失 `load_mode` 时继续使用 `eager`，不改变已有令牌行为。
- 新建和导入草稿默认 `progressive`，也可选择始终装载的普通提示词。
- 渐进式合集有 2–128 个独立技能，保存 `id/title/description/path/content/resources`。
  单技能主标题、说明和正文继续使用模板字段，`skills[0]` 保留身份、路径和引用资源。
- 渐进式发布要求包及每个子技能具有用途说明；下架草稿允许稍后补全。
- 按需模式单文件 8 MiB、包内文本合计 64 MiB，不使用原 32768 字节限制。
  始终装载模式继续保留单模板 32768 字节、合集 2–16 项和令牌启用合计 65536 字节限制。
- 路径必须为包内相对路径，引用资源只作为文本读取，不执行脚本。
- 文件导入或保存失败必须保留当前草稿，排序、编辑均不得丢弃技能身份和资源。

## 页面流程

管理员选择加载模式，按需模式分别编辑技能用途、主文件路径与引用资源。
安装详情说明每令牌最多八个安装包：普通提示词始终装载，按需技能仅将已读内容加入后续模型上下文。
按需读取会产生额外模型轮次，各轮独立计费；编辑器和安装详情均有说明。
合集未填写主文件路径时由服务端生成唯一目录；用户填写的主路径不能重复。
普通目录显示模式和摘要，不渲染技能正文或资源。

## 验证计划

覆盖超过 32 KiB 的单文件和合集保存、旧模板限额、用途缺失禁止发布、资源编辑和排序保留、
新建默认模式、模式切换、导入与保存失败保留草稿、用户端无正文及资源。
执行受影响交互测试、八份语言资源检查、ESLint、Prettier 和 Classic 生产构建。

## 验证结果

Classic 新增 11 项渐进式交互回归，覆盖超过 32 KiB、资源保留、路径边界、类型转换、
用途校验、导入失败保留草稿、用户摘要与旧模式兼容。既有中心 16 项和合集 12 项交互回归通过，
八份语言资源检查、受影响 ESLint、Prettier 及生产构建通过。

生产构建保留现有 Browserslist 数据过旧、Lottie eval 与大 chunk 警告。
本子任务未进行浏览器视觉检查；保留现有页面主体布局，只增加模式及资源编辑控件。
尚未提交或部署。

## 原生协议网关补充验收

独立只读审查后补充 Responses、Claude Messages 与 Gemini 原生 helper 回归。
使用真实令牌鉴权、分组路由、技能读取和结算链，模拟上游返回读取工具调用、
结束读取及最终回答，分别覆盖普通/透传与最终普通/流式响应。
检查 Responses 加密推理、Claude 签名思考及 Gemini 调用 ID/思考签名在续轮中保持，
最终恢复客户端工具与流式配置，私有轮次不返回客户端；钱包、令牌及消费日志逐轮核对。
如涉及 Gemini DTO，另执行 relaykit 独立回归与构建；不调用真实供应商、不部署。

原生三协议共 12 个组合通过，覆盖普通/透传与最终普通/流式响应。
Gemini 非透传真实 helper 先复现续轮 `functionCall.id` 丢失，透传路径保持；
补齐 `FunctionCall.ID` 后全部转绿，独立 DTO 回归也先红后绿。
字段遵循 [Gemini FunctionCall 官方契约](https://ai.google.dev/api/generate-content#FunctionCall)：
可选字符串身份在工具结果中使用相同 ID，思考签名同样原样保留。

每个组合实际经过令牌鉴权、分组路由及三轮独立结算：两次读取阶段、一次正式回答，
各扣 100 quota，钱包与令牌从 10000 降至 9700，生成三条消费日志。
三轮实际输入/输出用量分别为 20/5、20/5、40/10，日志只记录披露文件元数据。
未读取的资源、正文后续页及无关技能未发送上游，私有思考与内部工具不返回客户端。

执行 `go test ./controller -run TestGatewaySkillsNativeProtocolsPreserveContinuationAndClientRequest -count=1 -timeout=60s`
通过；`relaykit` 在 `GOWORK=off` 下全部 DTO 测试及独立 `go build ./...` 通过。
这里使用本地 SQLite 与模拟上游，不能据此声称三种数据库或真实供应商已经实跑。
