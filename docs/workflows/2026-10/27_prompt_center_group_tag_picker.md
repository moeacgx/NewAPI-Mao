# 提示词中心分组白名单标签选择

## 目标与范围

提示词中心管理员编辑模板时，按分组标签浏览并多选白名单分组，减少长分组列表的查找成本；技能目录卡片默认折叠支持分组，按需展开查看。Default 和 Classic 两套模板同步实现。

## 方案与契约

- 复用管理员已有的分组详情和分组标签数据。标签只负责筛选候选分组，不改变白名单授权、路由或计费。
- 选择结果继续提交 `group_ids` 数字 ID；`all_groups` 仍与显式白名单互斥。合集及其中所有技能继续共用模板级白名单。
- 可用分组按标签或全部分组浏览，并支持搜索及跨标签多选。已删除分组仍作为失效项保留，管理员可移除；不会自动删除既有白名单。
- 技能目录卡片默认不显示白名单分组名称；用户展开后才显示已返回的分组名称。不新增 API、数据库字段或迁移。
- 分组标签是显示与筛选元数据，不作为权限边界。模板白名单仍由现有稳定分组 ID 和后端按实际请求分组的授权检查决定。
- 读取现有 `GET /api/group/details` 与 `GET /api/group/tags`。Classic 直接复用令牌编辑的 `GroupTagFilter`、标签钩子及筛选函数；Default 使用自身 Base UI 组件实现同样的标签卡片与多选弹层。Default 另提供未分类标签，两套的全部分组入口均可选择无标签分组。
- 切换标签时只暴露当前弹层的选项，退出动画不保留旧弹层的重复复选框；安装、编辑、删除和合集详情操作不触发卡片分组展开。

## 安全与兼容

标签和分组详情均沿用管理员接口及权限。旧客户端的 `group_ids/all_groups` 请求契约保持兼容，已有模板、分类、安装和技能数据无需迁移。标签接口失败时仍提供全部分组选择，避免管理员被标签配置阻断。
