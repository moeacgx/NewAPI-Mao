用户要求将双模板提示词中心安装到 zzapi 测试。本轮只更新 zzapi 三个应用，不更新 maolaoapi，
不推送或合并功能到主线，不改现有渠道、令牌、分组、计费和主题配置。

## 部署与验证计划

1. 保存 Compose、环境文件、容器快照、数据目录和 PostgreSQL 自洽备份，核对归档和哈希。
2. 在独立构建目录校验源码压缩包与 revision，构建带唯一测试版本的镜像，准备回滚脚本。
3. 复验功能组合的后端与独立 relaykit，核对双前端构建；使用隔离数据库进行管理和装载验收。
4. 部署前确认现场未被其他任务修改；只替换三个应用镜像，完成主节点迁移后逐节点验收。
5. 核对三表、版本、健康、静态资源、未登录鉴权与依赖容器身份；记录实际验证范围。

不得以基础健康检查替代安装和转发验证；模拟上游不等于真实收费供应商。私有配置与备份
只保留在目标主机，验收记录不得包含令牌、Cookie 或数据库密码。

## 隔离业务验收

使用同一新镜像和同一 PostgreSQL 服务内的独立临时数据库，未接入业务 Redis 或真实渠道。
通过正常初始化、登录和管理 API 创建随机测试身份，所有凭据只保留在目标主机私有目录。

- 普通用户不能访问管理接口，管理员不能越过令牌所有权；模板创建、编辑和版本 409 冲突通过。
- 分组显示名称与 code 不同，持久化稳定 ID；安装、停用、卸载和徽标计数均通过。
- Chat、Responses、Claude、Gemini 四种协议分别验证白名单命中与不命中，共 8 次非流式
  模拟转发。原系统指令保留一次，命中时模板出现一次，不命中时模板不出现。
- 钱包扣费、8 条消费日志和仅 4 条命中请求的提示词审计正确，审计不含模板正文。
- 业务验收作业 `ca26c920-c484-4e40-8335-353863b414ea` 成功，脱敏结果保留在构建目录
  `isolated-verification.json`。测试结束后卸载绑定并下架模板。
- 初次测试脚本的密码长度不符合已有上限，随后修正；主机桥接网关请求被网络策略拦截，
  改为仅进入隔离容器网络命名空间执行模拟服务，未修改防火墙。另一次测试额度输入不足被
  正确拒绝，按现有 quota 单位修正测试数据后通过。没有为测试修改业务代码或放宽权限。
- 本轮未实测流式、auto 自动跨组重试、真实供应商或在线浏览器交互；本地已有相关回归，
  不能据此扩大本次远端业务验收结论。MySQL 未实跑。
