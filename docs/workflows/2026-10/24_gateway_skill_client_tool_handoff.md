# 云端技能读取与 Agent 工具交接修复

## 问题与范围

2026-10-24，zzapi 的本地 Agent 在渐进式技能读取阶段返回 HTTP 502，错误为
`gateway_skills_failed`，原因是模型返回了客户端 `pwsh` 工具调用。
线上消费审计表明故障发生在第一轮私有发现，尚未成功读取文件正文。

私有阶段保留客户端完整历史与系统指令，但只声明三个网关技能工具。
模型受到既有 Agent 工具历史影响时，可能继续调用客户端工具；原解析器将其一律当作未知工具拒绝。
本项仅修改网关后端，Default、Classic 操练场及外部 Agent 共用该链路，无前端或数据库结构改动。

## 方案与安全边界

- 从原始请求按协议取得明确声明的客户端工具名称；真正未知工具、缺失或重复调用 ID 继续拒绝。
  覆盖 Chat/Responses 现代 `function`、Claude 工具和 Gemini 函数声明，不覆盖 Chat 旧版
  `functions` 和 Responses `custom` 工具。
- 私有响应中的客户端工具只表示需要交回 Agent，不由网关执行，也不直接返回客户端。
- 同轮混合网关读取和客户端工具时，仍执行授权的读取，保留实际读到的正文。
- 已成功读取非空文件页后遇到客户端工具，结束私有阶段，重新授权已读内容，再从原请求进行正式生成。
  目录元数据和文件末尾的空 EOF 页均不能视为已读正文。
- 尚未读取正文时最多纠偏一次，明确要求先读相关技能；纠偏计入既有八轮总预算。
  不把意外客户端调用或伪造的执行结果回填给上游。再次提前调用客户端工具时返回明确错误，避免静默跳过技能。
- 完整保留原始工具历史、原工具配置、输出格式和流式参数；私有文本与调用不泄漏到正式请求。
- 每个真实模型轮次继续独立计费和审计；已结算轮次不因后续失败退款。

## 验证计划

- 先用带 `pwsh` 历史和声明的请求复现私有阶段误调用导致的 502。
- 覆盖读后交接、首次误调后纠偏并真正读到正文、混合调用、连续误调有界失败。
- 验证四协议工具声明识别、未知工具与重复 ID 拒绝、纠偏保留签名和历史。
- 覆盖 Chat 普通/流式与透传组合、实际出站正文、逐轮钱包/令牌扣款和消费日志。
- 通过本地检查后构建固定源码镜像，按既有授权仅逐一更新 zzapi 三应用节点。
  真实测试只检查模型列表、技能读取与客户端工具交接，不执行返回的客户端命令。

  每轮钱包/令牌扣款及消费审计。
