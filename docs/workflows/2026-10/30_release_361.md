[.360 通知模板升级和回滚边界](28_release_360.md)。本次不部署生产容器。

## 验证计划与发布门禁

1. 重新运行两套模板的设置布局、自动回复、归档与本地化相关回归，单个测试进程
   限制 60 秒；执行 Default 类型检查及 Markdown 格式、链接、差异检查。
2. 版本 PR 仅包含本记录、开发索引与 VERSION。提 PR 和合并前刷新远程，确认
   behind=0、准确 head SHA 的 CI 成功，完成独立只读审查。
3. 对版本合并提交创建新的附注标签，不移动旧标签；检查 Linux Release 和 Docker
   双架构作业，以及 Linux 二进制 SHA-256、ELF 架构、镜像版本与 latest 清单一致。
4. 实际 CI、发布作业和产物校验结果以对应 Release 说明为准；本记录不宣称线上
   业务验收通过。

## 验证结果

发布前完成源码独立只读审查，未发现行为、权限或可访问性阻断。Default 四个文件
22 项回归和类型检查通过；Classic 四个文件 16 项回归、两项布局约束通过。
Classic 首次合并运行触及 60 秒期限，拆成两批复核均退出 0。当前机器没有 Bun，
使用已有 Node 与依赖目录联接执行等价脚本，未修改锁文件；双模板生产构建由
准确提交的 CI 与正式发布作业验证。主工作区 64 个遗留变更已完整保存在 Git stash
`ba4a474ddb96d82a6b13a390bf66aa263446f237`，包括未跟踪文件；原工作区已快进
同步到远程主分支，备份保留以便追溯。
