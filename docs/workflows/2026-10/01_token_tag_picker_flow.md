# MAO-6 令牌标签直接选组与保存校验

## 目标与范围

用户反馈 Classic 令牌表单需要先选标签再点添加分组，且默认自动分组会阻止追加。
本轮仅改变 Classic 创建/编辑令牌交互，Default、后台标签管理、数据库及后端规则不变。

## 方案与契约

- 点击标签直接在该标签旁打开分组选择浮窗，重复点击当前标签可重新打开。
  标签存在时移除下方重复选择/添加按钮；没有标签时保留原有选组入口。
- 去掉外层重复的“令牌分组”标题；有选择时在分组列表上方显示带图标的“已选分组”标题，
  空选择不渲染空标题，减少表单层级并明确当前已选内容。
- 浮窗按标签筛选和搜索，仅排除已选择的分组，不因自动或独立分组禁用其他选项。
  追加不替换原选择，保留顺序、倍率保护与手动移除能力。
- 草稿允许自动/独立分组与其他组并存；提交前检查冲突，标出当前显示名称，
  提示移除其他分组或给独立分组单独分配令牌。冲突时不发送创建/更新请求、不清空草稿。
  不自动拆分令牌，不把选择动作视为合法保存。
- 独立或 auto 单选、普通多选、无选择继承继续沿用原 `group/group_ids/group_mode` 提交契约，
  后端独立分组和自动分组校验保持。显示名称不替代稳定 ID/code。
- 浮窗可键盘打开、搜索、选择、Escape 关闭，关闭后焦点回到标签。
  标签管理共用筛选器保持原过滤行为，失效标签回退不会自行打开浮窗。

## 验证计划

- 回归覆盖标签直接打开/重开、后台筛选不弹窗、跨标签保留、auto/独立草稿自由追加、
  新建及编辑保存冲突无请求且草稿保留、移除冲突后成功提交、合法单选和无标签入口。
- 涉及 JSX lint、格式检查、七语言及简体兼容语言同步、Classic 构建。
- 本地实际组件演示及 Playwright 桌面/移动端截图、焦点/浮窗溢出检查；fixture 不等于线上验收。

## 验证结果

- Classic JSX ESLint、Prettier、`git diff --check` 通过。
- `npx --yes --package bun bun run build` 通过；仅有仓库既有 Browserslist、lottie `eval` 与大 chunk 警告。
- 本地 Playwright 演示通过桌面 1440px 与移动 390px：标签直接打开浮窗、弹窗不越界、自动/独立分组冲突阻止提交且保留草稿、移除冲突后稳定 `group_ids` 提交、搜索与键盘关闭/重开正常。
- Classic 分组标签兼容测试 20 项全部通过；令牌保存契约、跨标签选择与保存冲突分别覆盖。
- Classic 分组标签兼容测试现为 21 项，新增已选分组标题与图标的显示/空状态断言。
- `i18n:lint` 仍受仓库既有全量硬编码问题阻断，本次新增文案已通过 `i18n:sync` 写入七种语言。
- 本轮不操作生产容器，也未提交、推送或发布。
