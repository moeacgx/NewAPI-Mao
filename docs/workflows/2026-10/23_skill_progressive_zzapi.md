# zzapi 渐进式技能测试部署

## 目标和范围

用户要求将网关渐进式技能更新到 zzapi。仅更新该测试集群的三个应用容器，
不更新 maolaoapi、不推送源码、不创建 PR、不发布正式版本。

本轮源码为 `db7e411577fe28b351df49b619c8e1aeafafb40f`，包含现场旧源码
`b476e8bc93ff5bca9acc728fe7752d95a6c0432c` 的全部历史。
部署前通过 CloudSSH 实时确认三应用健康、重启计数为零，旧镜像为
`newapi-mao-zzapi:skills-b476e8bc93ff`。

## 实施计划

- 使用独立源码包构建唯一镜像 `newapi-mao-zzapi:progressive-db7e411577fe`，
  版本 `zzapi-progressive-db7e411577fe`，镜像记录完整源码 revision。
- 备份 Compose、环境、私有容器快照、数据目录与 PostgreSQL 自洽 dump；
  检查备份目录、归档内容和 SHA256，不把备份检查表述为恢复演练。
- 同一镜像运行独立测试实例，使用隔离数据库和模拟上游验证渐进式导入、
  大于 32 KiB 的文本存储、按需读取、旧全文模式、普通用户正文隐藏和双模板资源。
- 按 `zzapi`、`zzapi-slave-1`、`zzapi-slave-2` 顺序更新，逐节点通过健康、
  版本与未登录权限检查后才更新下一节点；保留主节点原环境及两个从节点的 `NODE_TYPE=slave`。
- 保留环境、挂载、端口、主题和业务配置，不重启 PostgreSQL、Redis；
  比较新增迁移与既有技能数据，核验公网状态、页面和静态资源。

## 数据、计费与回滚

新增 `prompt_templates.load_mode` 以及 `prompt_skill_records`、`prompt_skill_files`、
`prompt_skill_chunks` 三表和索引，旧模板仍为全文模式，不批量转换。
渐进式模板允许文件大于 32 KiB，按页披露仍受读取预算和模型上下文约束。
网关私有模型轮次分别预扣、结算和记录用量，真实调用会增加费用与等待时间。

回滚保留新增表、字段与内容，不自动还原业务数据库。只有尚无渐进式业务模板时，
才允许回到本次旧镜像；仅停用渐进式模板不足以保证旧管理目录、安装详情和编辑器兼容。
已有渐进式数据时优先向前修复，不能让旧编辑器覆盖独立文件。备份与回滚脚本保存在远端本轮私有目录。
隔离验收不向业务库新增测试用户、令牌、模板、分组或渠道，不调用真实供应商。

实现与本地验证见[渐进式技能记录](23_skill_progressive_disclosure.md)。

## 使用与共享契约

刷新页面后，新建或重新导入默认按需读取。已有模板需要管理员在编辑器中切换至渐进式并保存，
原有安装关系继续生效；不自动批量转换。引用资料需要随 ZIP 或仓库重新导入，旧全文版本未保存的
附件不能凭空恢复。仅文本文件参与装载，私有模型轮次和正式生成分别计费。

API 令牌格式、模型 ID 和客户端请求地址保持原契约；启用渐进式后一次客户端请求可产生多次上游消费。
NewAPIForDouDi 值得参考目录、分块及授权设计，需适配分组与逐轮计费；NewAPIModifyByGang
在已有技能中心的情况下值得参考，需适配导入器、管理界面和网关工具循环。本轮未向兄弟项目发送消息。
