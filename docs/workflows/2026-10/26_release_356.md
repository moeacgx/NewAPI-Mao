1. 逐项代码复核、必要回归；每次合并前 fetch 并确认分支不落后。

3. 独立版本准备 PR 将 VERSION 更新为 `v1.0.0-rc.10.1.10.356`，通过 CI 后合并。
4. 在准确发布提交创建附注标签，等待 Linux 二进制及 Docker 双架构工作流；核对资产 SHA-256、镜像 version/revision 与架构。

- 工单统计新增管理员只读接口 `/api/ticket-admin/stats`，由 AdminAuth 与 `tickets:read` 保护；提醒仅使用 `open`。
