# 操练场 API 令牌切换

## 目标与方案

Classic 与 Default 操练场保留默认账号调用，增加可搜索、分页的本人 API 令牌选择。
选中令牌后不读取前端完整密钥，而是在原 `/pg/chat/completions` 请求头传入
`X-Playground-Token-Id`。服务端先验证登录身份与令牌归属，再复用正式 TokenAuth、
模型限流、分组分发、计费及提示词装载链路；控制器不再覆盖为临时令牌。
未选令牌的调用保留原有行为。

令牌模式不提交操练场的账号分组选择，由令牌自身的分组、自动分组和跨组重试规则决定路由。
`GET /pg/token/models` 携带同一请求头，使用正式令牌模型发现接口的结果；令牌无效时显示错误，
不回退账号模式。选中令牌仅存于当前页面内存，切换时清除过期模型选择，请求期间禁止切换。
令牌摘要列表复用现有本人令牌分页/搜索接口，展示名称、分组显示名称与技能数量，
不调用密钥读取接口，不显示提示词正文。

## 安全与兼容边界

- 只有登录用户可以按 ID 选择自己的令牌，管理员同样不能选择他人的令牌。
- 令牌禁用、过期、额度、IP、模型、分组、并发与限流限制继续生效。
- 显式选择失效令牌必须拒绝，不能静默使用账号余额绕过令牌限制。
- 普通与流式请求使用相同令牌身份；日志与额度扣减归属该令牌。
- 不修改数据库结构，不增加第三方依赖，不自动请求真实供应商。
- 本次同时覆盖两套前端，不修改已有对话内容或默认账号模式的分组规则。

## 验证计划

后端覆盖归属隔离、无效输入、禁用/过期/IP 限制、分组越权与模型约束，
以及模拟上游正文中真实装载内容、日志令牌身份和额度结算。
前端覆盖搜索/分页、选择/返回账号模式、失败不降级、请求中的令牌头与账号分组省略、
流式一致性和生成期间禁用；运行受影响测试、类型检查、lint、格式检查和双模板构建。
