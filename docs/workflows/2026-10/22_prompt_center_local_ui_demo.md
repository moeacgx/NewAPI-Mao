# 提示词中心本地 UI 演示

## 范围

用户要求先本地渲染 demo。仅本地修改和演示，不更新 zzapi，不发布或合并。
两套真实前端使用独立本地 SQLite 演示库，模板、令牌和账号均为演示数据。

## 页面与权限契约

- 按用户选定的浅色蓝色截图定稿，Classic 与 Default 同步采用全局圆角容器、浅色标题区、
  蓝色主标记和右侧统计；说明与搜索置于标题区底部，下方为三列模板目录。
- 模板卡片不重复显示装饰图标或编号，标题与发布徽标同排；分组位于底栏左侧，蓝色
  “安装到令牌”按钮位于右侧。手机降为单列，保留明确的模块边界。
- 令牌选择统一为可搜索的列表弹窗，移除原生下拉框；列表提供令牌图标、安装数量、
  选中标记、加载、空状态、失败重试和分页。搜索和翻页保留已选令牌，
  确认后进入安装管理。
- 普通用户仅提供安装、卸载及保存操作，移除正文详情、启停开关和排序按钮。
- 普通目录 GET、安装列表 GET 及安装 PUT 响应统一使用不含 `content` 的摘要。
  管理员模板接口与编辑器仍提供正文，运行时装载及服务端字节校验保持原逻辑。
- 本地预览地址为 Classic `http://127.0.0.1:32124/console/prompt-center` 和 Default
  `http://127.0.0.1:32125/prompt-center`；演示登录状态仅保存于本地被忽略目录。

## 验证

### Classic 主色对齐

Classic 原先沿用 Semi 默认深蓝色，导致结构调整后仍与用户选定的 Default 浅蓝版不一致。
提示词中心页面、令牌选择弹窗、安装管理弹窗和模板表单改用模块局部主题变量，主色直接
取自 `web/src/styles/theme.css` 的 `oklch(0.692 0.141 243.716)`；同步按钮、主标记、
发布徽标、辅助图标以及选中、悬停和聚焦状态，不修改 Classic 全局主题。
验证包括 CSS/Markdown 格式、Classic 生产构建及桌面、手机、令牌选择弹窗的真实浏览器
截图，并核对按钮和主标记计算颜色与 Default 主色相等。

本轮 Classic 生产构建和格式检查通过；本地重新打包后检查 1440px 桌面、390px 手机及
令牌选择弹窗。浏览器将两套实际安装按钮颜色转换为 sRGB，均得到 `rgb(62,164,236)`；
Classic 主标记及弹窗聚焦边框也使用同一主色。无远端发布。

Default 30 项测试、类型检查、lint 和格式检查通过；Classic 16 项交互与八语覆盖、lint
和格式检查通过。后端目录、安装列表和保存响应不返回正文，管理员列表仍保留正文；对应
控制器回归通过。浅色定稿产物执行双模板构建和 1440px 桌面、390px 手机浏览器检查。

演示为本地 UI 预览，未进行本轮远端或真实供应商验收；前一轮线上版本保持不变。
