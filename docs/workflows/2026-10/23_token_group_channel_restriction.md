# 令牌按分组限定渠道

## 目标与范围

管理员在创建或编辑本人令牌时，为每个已选显式分组分别填写一个渠道 ID。
Default 与 Classic 均提供入口；同一令牌密钥保持不变。普通用户不能设置该参数。

## 数据与权限契约

- `POST /api/token/`、`PUT /api/token/` 接受 `group_channel_ids`，键是稳定分组 ID，值是正整数渠道 ID。
- 渠道 ID 范围为 `1..2147483647`；字段省略时管理员编辑保留仍绑定分组的设置，空对象清空设置。移除分组同时移除其限定。
- 仅 Admin/Root 可新增或变更限定，且仍只能编辑本人令牌；服务端独立校验。普通用户显式提交字段（包括空对象）返回 403。
- 管理员降权后，带限定令牌的调用及普通编辑返回 403，不能通过省略字段或切换分组解除限制；仍允许 `status_only` 状态切换。恢复管理员身份后才可编辑或清空限定。
- 限定保存在 `token_groups.channel_id`，不把显示名称或 code 用作新关联身份。
- 保存时渠道必须存在、启用并绑定对应分组。自动分组和继承模式不支持限定。
- 模型限制、分组权限、可用状态、能力、路径和并发仍按正式链路校验。

请求示例（分组名称只用于界面展示，不作为提交身份）：

```json
{
  "group_mode": "explicit",
  "group_ids": [11, 22],
  "group_channel_ids": {
    "11": 952,
    "22": 958
  }
}
```

## 路由与生命周期

该组只从指定渠道选取，未指定的组保留现有分发。亲和与重试遵循同一限定；
指定渠道不可用、被移出分组或不支持模型时，不得落到该组其他渠道。
多显式分组保留既有顺序和跨组重试：耗尽当前组可推进下一授权组。
带逐组限定的令牌不能同时使用旧式密钥渠道后缀，冲突请求返回 400。
视频 remix/续作锁定原任务渠道前也核对当前分组限定；冲突返回 403 `task_channel_ineligible`，不改投其他渠道。
按稳定分组 ID 保存，分组改名或历史 alias 变化不改变限定；移除令牌分组绑定时清理对应限定。
指定渠道删除、停用或被移出分组后，保留限定并按正式路由失败处理，管理员需主动清空才恢复正常选渠。

普通显式分组迁移时，存续令牌的源分组有限定则预览、执行均拒绝；必须先由管理员清空该限定。
其他保留组的限定保持不变。迁移至 `auto` 是管理员明确选择的全解绑操作，沿用既有契约，清空全部显式分组绑定及限定。
分组删除需遵守已有绑定清理与迁移门禁，不能通过迁移到另一显式分组静默抹掉源限定。

新增列使用 GORM 迁移，兼容 SQLite、MySQL、PostgreSQL；回滚应用前应清空限定，
旧应用不识别该字段，不能保证测试请求仍限定渠道。所有实例需同时升级后使用。

## 验证计划与状态

验证管理员保存/清空/省略保留、普通用户越权、无效 ID/错组/禁用渠道、
移除分组与改名、缓存重读，以及初选/亲和/重试的候选交集。
前端验证逐组输入、普通用户隐藏、提交稳定 ID、删除组清理和双模板检查。
两套前端均补齐 7 语言的 5 个界面键；Classic 同时补齐实际简体中文入口 `zh-CN`。
两套模板分别执行 `i18n:sync`，最终差异只保留本任务相关翻译，保留原有历史键及受保护的归属信息。
本地验证：后端 model/controller/service/middleware 的令牌、分组、选渠与分发相关回归通过；
relay 的原任务授权回归通过，包含限定与原渠道一致、冲突拒绝且不锁定渠道。
Default 22 项、Classic 25 项组件及表单测试通过，Default 类型检查、两套涉及文件 lint 与生产构建通过。
Markdown 格式化、翻译占位符、新增文档链接与 `git diff --check` 通过。
前端测试存在既有 jsdom navigation、Semi React 弃用提示；Classic 构建有大 chunk 提示，未阻止通过。
未部署、未调用真实供应商，未实测 MySQL/PostgreSQL 或真实浏览器交互。

## 跨项目与分享边界

兼容 API 新增令牌管理字段，不改变模型 ID、密钥本体、usage 或计费契约；只有主动配置限定的令牌改变候选渠道。
ApiPanelWatch、Sub2API 等若维护令牌配置，应保留该可选字段，并遵守管理员权限和省略保留语义。

- `NewAPIForDouDi`：适合分享管理员测试选渠能力，需先核对其分组身份、令牌绑定和重试链路，不能只移植表单。
- `NewAPIModifyByGang`：同样有测试价值，须评估其缓存、迁移与管理员降权处理是否可满足完整约束。
