# 工单状态概览

## 目标与范围

将 Default 与 Classic 看板的待处理工单大卡片扩展为四项工单状态概览：待处理、进行中、已解决、已关闭。每项包含状态图标、名称和数量，点击进入对应状态列表。保留顶部刷新与工单管理入口，窄屏使用两列布局。

## 数据与权限契约

- 新增 `GET /api/ticket-admin/stats`，使用现有管理员认证与 `tickets:read` 权限，返回 `{success:true,data:{open:0,processing:0,resolved:0,closed:0,archived:0}}`。
- 单次分组聚合查询，排除软删除工单，缺失状态填零；归档单独计数，不并入已关闭。不返回工单正文或用户数据。
- 看板显示四个主要状态；浮窗只使用 `open`，不把进行中计为待处理。
- 两套模板保持身份复核、账号切换隔离、取消信号、10 秒超时、可见页 60 秒轮询与权限撤销清理；失败显示错误，不把失败伪装成零。
- 无数据库结构变更；GORM 聚合兼容 SQLite、MySQL、PostgreSQL。

## 验证计划

- 后端：状态分组、空库零值、软删除排除，管理员权限与未登录/普通用户拒绝。
- 前端：四项不同数量、状态跳转、刷新、错误/重试、浮窗仅待处理、账号隔离；两套构建、类型与格式检查。
- 浏览器：桌面四列、手机两列、图标与数字布局；部署后管理员只读验收。
