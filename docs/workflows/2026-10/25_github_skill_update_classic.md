# Classic GitHub 技能来源与更新

状态：本地实现与验证完成，未部署。基于 `origin/custom-main` 的 `8d0f1874db8b8a34984fdfc7380ca51bf9e7c056`。

## 范围与契约

仅修改 Classic 提示词中心，保持现有浅蓝卡片布局。管理员管理模式显示 GitHub 来源 URL、引用、目录和短提交号，并提供更新操作。
普通用户和没有来源的模板不显示更新入口。导入草稿通过 `repository_source` 保留来源，保存完整提交该字段。

更新调用 `POST /api/prompt-center/admin/:id/update-repository`，请求携带当前 `version` 和 `overwrite_local`。
成功返回 `template` 与 `updated`；界面以服务端模板刷新该卡片，分别提示更新完成或已经最新。
本地修改时先确认覆盖正文和引用文件；服务端返回 `repository_local_changes` 时亦允许确认后重试。
其他错误保留原卡片、展示错误且允许重试。进行中的更新禁止重复提交。

已有模板重新导入仓库时保留模板 ID、版本、分类、白名单、上下架和排序；新建导入继续产生未发布草稿。
前端只显示来源元数据，不读取或向普通用户暴露技能正文。不自动轮询仓库，不执行脚本。

## 验证计划

- 来源显示与导入保存、旧模板重新导入身份保留。
- 管理员更新成功、无变更、失败、版本冲突、本地修改确认/取消及提交中禁用。
- 普通用户和无来源模板没有来源或更新入口。
- 提示词中心交互回归、八份语言覆盖、受影响 ESLint/Prettier 和 Classic 生产构建。
