# Classic 使用日志分组角标

## 目标与范围

按用户截图调整 Classic 使用日志：技能提示放到分组标签右上角，使用小图标徽标，悬停显示详情。类型列恢复仅展示日志类型，不增加技能列或列选择开关。Default 本次不在范围内。

## 交互与数据契约

- 复用现有 `getLogSkillUsage`、`describeLogSkillUsage`：已使用、可用但未读取、私有发现轮次三种语义不变。
- 已使用为紫色角标，其余为灰色；表格内不铺开技能数量、轮次或名称，只在悬停或键盘聚焦时展示完整文案。
- 分组显示名、原始分组、历史 `other.group` 的展示优先级不变；缺少分组但存在技能信息时以 `—` 为锚点保留徽标。
- 角标绝对定位于分组右上方，不额外增加列宽；分组复制仍可用，点击角标不复制分组也不触发行展开。
- 展开详情中的技能信息保留，便于移动端阅读；沿用现有日志权限，不修改后端、计费或技能读取逻辑。

## 验证计划

验证三种技能状态的悬停详情、键盘聚焦、无技能、旧日志分组回退、缺少分组、类型列不再显示技能文字及角标点击事件隔离。运行相关 Classic 测试、格式与 lint、构建，并用真实组件本地预览检查位置。

## 验证结果

- 技能角标 12 项、展开详情 3 项交互测试通过；解析和多语言 10 项通过，共 25 项。
- 修改的 JS/JSX 文件 ESLint 与 Prettier、文档格式及 `git diff --check` 通过。
- Classic Vite 生产构建通过（1 分 15 秒），保留既有大资源包及 Browserslist 数据过期警告。本次无 TS 变更；环境未安装 Bun，使用现有 Node 及已安装依赖运行等价命令。
- 本地 Chrome 使用真实列定义及模拟数据验证：角标位于分组右上角，类型栏只保留消费标签；技能详情显示数量和名称，Escape 可收起。不代表生产日志页面验收。
- 独立只读审查无阻断项。未提交 PR、未部署；Default 未修改，前一项工单看板工作在独立工作树中保留。
