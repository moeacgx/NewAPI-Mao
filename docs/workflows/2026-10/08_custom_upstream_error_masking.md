# 自定义上游地址错误脱敏

## 目标

错误信息需要保留公共文档链接和模型标识的可读性，同时不能把管理员配置的
自定义上游地址、渠道代理、环境代理或其凭据返回给客户端。

## 行为契约

- 请求错误响应和渠道错误日志按当前请求收集自定义 `base_url`、渠道代理、
  环境代理，以及实际请求地址。
- 预置的官方渠道地址继续保持可读；自定义上游主机、路径和网络错误中的裸
  主机名会脱敏。
- 所有 URL 的查询参数值、用户信息、`api_key` 值和 IPv4/IPv6 地址都脱敏，
  即使它们出现在公共 URL 或没有可用上游地址的错误中。
- 普通域名、文档链接、邮箱域名和模型名中的点号不会被误改。
- `MaskSensitiveInfo` 和 `NewAPIError` 的新参数为可选参数，旧调用仍可编译；
  中继请求路径显式传入当前请求的上游地址集合。

## 兼容性与边界

只改变错误消息的展示和日志脱敏，不改变上游请求 URL、认证头、重试判断或计费。
公共预置地址的判断按完整 host（包含端口）进行，避免把管理员配置的本地服务
误认成官方地址。生产部署前仍需用真实自定义域名和代理配置做端到端错误响应验证。

## 验证

```text
cd relaykit
go test -timeout 60s ./relayconvert/kitutil/...
cd ..
go test -timeout 60s ./controller -run '^$'
go test -timeout 60s ./service -run '^$'
git diff --check
```

脱敏测试覆盖自定义域名、IPv4/IPv6、查询凭据、用户信息、绝对路由、公共文档
链接和带端口的国家代码域名。
