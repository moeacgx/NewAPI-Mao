# Classic 已安装提示词弹窗与提示词中心筛选优化

## 目标与范围

按用户截图优化 Classic 令牌列表「技能」徽标打开的已安装提示词弹窗，以及提示词中心的分类与技能类型筛选。截图已从源码确认属于 Classic；Default 不在本次范围内。

## 问题与根因

- `TokenPromptBadge` 的弹窗宽 620，没有 `prompt-installation-modal` 类，也没有 `prompt-center-page prompt-installation-content` 包装。提示词中心的局部主题变量因此不生效，已安装列表沿用目录默认的三列网格，卡片拥挤。
- 提示词中心安装弹窗已有 760 宽度和包装，两处入口外观不一致。
- 已安装项均使用同一个 Power 图标，不能区分单技能、合集或停用状态；数量、说明、保存按钮挤在同一标题行。
- 分类与技能类型筛选使用无样式的原生下拉框，层级和状态不清晰。

## 方案

- 新增 `TokenPromptInstallationModal`，令牌徽标和提示词中心共用同一弹窗外壳：宽 760、窄屏 `calc(100vw - 24px)`、局部主题变量。标题只显示令牌名称（长名称省略并保留完整 `title`），「已安装提示词」由正文区块标题说明，避免重复。徽标入口保留「打开提示词中心」链接。
- `TokenPromptManager` 改为单列列表：图标区分单技能与合集，下架或停用项灰显并标注；新加入未保存的项标注「待保存」；允许分组以 `group.name` 标签展示。标题区显示 8 格容量与 `n/8`，主说明与限制说明分层。保存移到底部操作栏，显示是否有未保存修改，并提供「放弃修改」恢复为最后一次保存的列表。
- 提示词中心分类筛选改为带图标与箭头的样式化原生 `select`，保留 `all`、`0`（未分类）和分类 ID 值；技能类型改为原生单选按钮组成的分段控件，值仍为 `all`、`prompt`、`bundle`，方向键可切换，并显示当前分类与搜索条件下的数量。筛选非默认时显示「重置筛选」。

## 契约与边界

- 仅展示层改动：不改 API、权限、计费、保存与卸载请求，保存仍提交完整 `bindings` 列表；卸载仍需保存后生效。
- 不展示提示词正文；分组只展示 `group.name`，不展示 code。
- 「放弃修改」只恢复本地草稿，不发送请求。
- 使用现有 Lucide 图标、Semi 组件和主题变量，不新增依赖；兼容暗色主题、窄屏和长标题。
