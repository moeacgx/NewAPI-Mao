# 待处理工单卡片操作区视觉优化

## 问题

Default 与 Classic 的待处理工单卡片右侧操作使用普通文字按钮和裸链接，图标、层级和点击区域不够清晰。

## 修改范围

- 两套模板的卡片标题保留工单图标，并增加轻量图标容器。
- 刷新、重试和查看待处理统一使用图标按钮/操作链接，扩大可点击区域并保留文字辅助。
- 查看待处理使用列表图标和右箭头，刷新使用刷新图标；不改变接口、权限、数量口径或跳转地址。
- Classic 同步调整卡片 CSS，保持其主题变量和组件体系。
- Classic 查看入口的按钮样式仅作用于卡片操作区，浮动提醒仍保留原有链接样式；窄屏允许操作组换行。

## 验证

- Default 待处理工单测试覆盖数量、刷新/重试、查看链接和权限行为。
- Classic 待处理工单兼容测试覆盖卡片操作可访问性与跳转地址。
- Default 类型检查、受影响文件 lint/格式检查；Classic 兼容测试和构建按发布流程执行。
