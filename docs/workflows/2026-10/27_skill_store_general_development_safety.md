# 技能商店通用编程开发安全助手

## 目标与范围

移除技能商店中的代码审查助手、专业写作合集和研究核验合集，新增一个通用编程开发技能。
新技能要求 agent 准备执行递归强制删除操作时先核验必要性、用户授权和目标范围；未获明确授权不得执行。

## 实现与安全边界

- 内置商店清单仅发布 `general-development-safety` 单技能，分类为“开发编程”。商店界面与导入接口
  由清单动态驱动，无需新增页面硬编码。未列入清单的旧条目不展示，也不能通过其旧条目 ID 导入。
- 技能限定递归强制删除操作的授权语义：用户仅要求一般清理、修复或编写技能，或仅讨论该命令，
  不构成执行授权；替换成另一种 shell 删除命令也不能绕过限制。
- 执行前须独立核验删除理由与替代方案、精确路径和命令展开范围、授权边界及可恢复性。
  目标不明确或超出授权时停止；不得公开内部思维链，只说明简短可审查的理由和目标。
- 从内置仓库删除旧预设文件，避免它们继续随应用打包；不触及站点数据库中的既有导入副本。
  商店导入继续产生未上架草稿，权限、分组、计费和技能运行接口不变。

## 验证

- 更新新技能文件 SHA256，运行 `go test ./service -run SkillStore -timeout=60s`，确认内置商店清单、
  文件校验和及草稿导入行为。
- 检查 Markdown 格式、相对链接和 `git diff --check`。

本项只更新仓库内置商店快照和开发文档；未推送在线商店、修改站点数据或部署。

并结合其项目的授权与文件保护规范调整；本次未向兄弟仓库发送通知或创建 Issue、PR。
