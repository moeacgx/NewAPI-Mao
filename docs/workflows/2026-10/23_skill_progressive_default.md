# Default 渐进式技能管理界面

## 目标与范围

本项只修改 Default 提示词中心。Classic 由独立任务处理，运行时与存储由后端任务处理。
保留当前页面容器、浅蓝配色和令牌安装流程，为管理员提供渐进式技能的元数据和资源编辑。

## 数据与安全契约

- 新建技能使用 `load_mode=progressive`；旧模板缺失该字段时按 `eager` 显示和保存。
- 始终装载模式继续按 UTF-8 字节校验单项 32768 字节、合集 2 至 16 项及拼接正文。
- 渐进式模式不拼接合集，单文件最多 8 MiB、文本合计最多 64 MiB，合集 2 至 128 项。
- 每包最多 4096 个文本文件（含技能主文件），入口和引用路径最多 1024 UTF-8 字节。
- 发布渐进式技能需要用途描述。子技能保留稳定 `id`、入口 `path`、`description` 和
  `resources:[{path,content}]`。单项由模板主标题、说明和正文编辑，资源仍存于 `skills[0]`。
- 资源仅允许技能目录内相对路径，拒绝绝对路径、反斜杠、冒号、NUL、`.`、`..`、空路径段及重复路径。
  引用文件不得占用主文件名 `SKILL.md`（大小写不敏感）；技能入口路径按包内位置保存。
- 新 Markdown、ZIP、仓库和商店导入默认渐进式模式。ZIP 上限 16 MiB，可导入最多 128 项技能。
- 切换始终装载模式时明确提醒保存会移除引用资源；未保存切回渐进式模式仍能恢复资源草稿。
- 普通用户只查看摘要、加载模式和安装状态，不增加正文或资源查看入口。
- 管理员保存和导入失败保留草稿；网关读取不执行技能脚本。
- 安装上限按 8 个技能包说明，始终装载提示词共享 65536 字节上限；渐进式仅将已读取文本放入上下文。
  页面说明额外模型读取轮次会计费用量，模型上下文限制仍然适用。

## 验证计划

覆盖超过 32 KiB 的技能保存、合集独立校验、旧模式限制、描述缺失、资源路径和保留、
模式切换和错误后草稿。执行受影响交互测试、类型检查、格式、静态检查和 Default 构建。

## 验证结果

- 提示词中心 7 个测试文件共 57 项通过，覆盖用户摘要不泄露正文、导入默认模式及旧模板兼容。
- 新增渐进式回归共 15 项通过，并在最终静态检查调整后单独复跑通过：超过 32 KiB 保存、用途必填、
  同名技能独立路径、资源路径与大小、失败草稿保留、模式切回恢复、合集重排保留资源归属。
- Default 类型检查、受影响模块 oxlint、TypeScript/TSX 与七语 locale 格式检查通过。
- `i18n:sync` 通过，新增 33 个键的七种语言均已填写；既有未翻译项不在本次范围内。
- Default 生产构建通过。本子任务未运行真实浏览器或真实模型调用，界面视觉仍沿用现有卡片样式。
- 未提交、发布或部署；端到端网关读取、计费与 Classic 由对应集成任务验证。
