# Classic 提示词中心与令牌技能徽标

## 范围与入口

本项只实现 Classic 模板，Default 由独立工作项实现，共享
[令牌提示词中心契约](../../developer/token-prompt-center.md)。入口为
`/console/prompt-center`，控制台侧栏使用 `prompt_center` 开关，并在管理员与个人
侧栏设置中提供对应选项。

目录列出标题、说明、当前白名单分组名称及可展开的原始文本。用户可分页搜索自己的令牌，
安装模板，调整顺序、启停与卸载；未选令牌或正在读取安装列表时禁用安装。
管理员可新建、编辑和上下架模板，使用稳定分组 ID 保存白名单，更新提交当前 `version`。
所有写入通过独立提示词 API，不读取完整令牌密钥，不修改令牌额度、路由或其他权限。

## 技能徽标

桌面表格与手机卡片均在令牌名称旁显示「技能 · 数量」。未安装隐藏，全部未启用时灰显。
徽标使用后端的 `prompt_count`、`enabled_prompt_count`，具备完整可访问名称，支持键盘打开。
详情列出安装项、启用状态与当前分组显示名称，可直接调整顺序、启停和卸载。
修改成功后通知令牌列表刷新计数；徽标不代表每个调用分组都生效。
桌面长名称使用省略与原文提示，避免挤占相邻列；手机保留自动换行。

## 边界与失败处理

- 文本导入仅浏览器读取 `.md` / `.txt`，包括作为文本导入的 `SKILL.md`；不执行脚本、
  工具、附件，也不提供完整 Skills 运行环境。
- 模板正文上限 32768 UTF-8 字节；前端校验标题、正文，上架模板要求白名单，下架草稿允许空白名单。启用正文总量限制为
  65536 字节，每令牌最多 8 项。后端必须独立执行同样校验，前端校验不构成授权边界。
- 已下架安装项可查看、停用及卸载，不能重新启用。操作失败保留原安装列表并展示错误。
- 安装引用模板当前版本，后续修改由后端在新请求中生效；网页明确实际分组白名单语义与
  输入 Token 计费范围，列出支持的四种对话协议。
- 中英文、繁体中文、法语、俄语、日语和越南语均提供对应文案；`zh-CN` 别名资源同步。

## 验证

使用 worktree 独立依赖执行 `bun install --frozen-lockfile`。检查命令：

```powershell
node scripts/run-compat-tests.mjs src/pages/PromptCenter/__tests__/center.compat.test.jsx
node --test src/pages/PromptCenter/__tests__/i18n.test.mjs
node node_modules/eslint/bin/eslint.js <本次改动的 JS/JSX 文件>
bun run build
git diff --check
```

提示词交互测试覆盖安装、停用、卸载、保存失败恢复、排序与启用状态保留、下架、安装数量上限、
空目录、普通用户管理入口隐藏、管理员版本与分组 ID、单项 UTF-8 字节上限、启用总量上限、
桌面和手机徽标、键盘打开以及名称与 code 不同的分组显示。国际化测试检查各语言覆盖、
动态占位符和中文徽标实际渲染文本。

2026-10-22 本地结果：最终 12 个提示词交互测试（包含失效分组移除）、5 个既有桌面/手机令牌回归和 1 个国际化测试
均通过，受影响文件 ESLint、生产构建、Markdown 格式与 `git diff --check` 通过。

新增模块格式检查通过；既有 `helpers/render.jsx` 混用分号造成整文件 Prettier 不通过。
该文件本次只增加两行侧栏图标映射，沿用相邻格式，未扩大为整文件格式重写。
本地浏览器确认桌面徽标、安装详情与 390×844 手机卡片中的徽标可见且布局正常。

本项没有 TypeScript 变更，Classic 未配置独立 typecheck 脚本。生产构建包含原有
Browserslist 数据过期、第三方 `lottie-web` eval 和大 chunk 提示；不得将本地 adapter
交互测试视作真实供应商调用、生产安装或运行时注入验收。
