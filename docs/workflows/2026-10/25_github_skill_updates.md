# GitHub 技能来源、一键更新与删除

状态：本地实现与验证完成，尚未提交 PR、发布或部署。目标基线为 `origin/custom-main@8d0f1874d`；
Default 与 Classic 同时提供管理入口。

## 目标与范围

- 公开 GitHub 仓库、目录或 `SKILL.md` 导入后记录来源，管理员可以一键重新读取来源并更新站点副本。
- 管理员可以删除已添加的技能（模板），删除时自动卸载所有令牌安装。
- 用途说明取消 512 字符限制；导入时完整保留外部技能说明。见[导入元数据记录](25_skill_import_metadata.md)。

不开启定时同步，不执行仓库脚本；ZIP、Markdown、商店导入不记录来源，历史导入不反推来源。

## 数据与接口契约

- `PromptTemplate` 新增 `repository_source_json`（TEXT，GORM AutoMigrate 在三库新增列，无破坏性变更）。
  管理员模板与导入草稿返回 `repository_source:{url,ref,path,commit,imported_at,content_hash,locally_modified}`；
  `locally_modified` 读取时计算，保存时忽略。用户目录与令牌安装摘要使用公开结构，不返回来源。
- 保存时提交来源需通过校验：GitHub HTTPS 且无认证、端口、查询和片段，引用与目录为安全相对路径，
  40 位提交、64 位指纹和正数导入时间。旧客户端更新已有模板时省略来源即保留原记录。
- 内容指纹忽略随机技能 ID，覆盖装载模式、类型、主文件路径、正文和排序后的引用文件，以及合集内
  技能标题与说明；单技能的标题与说明是站点设置，不计入，因此只改单技能显示名称或说明不会触发覆盖确认。
- `POST /api/prompt-center/admin/:id/update-repository`，请求 `{version,overwrite_local}`：
  - 版本不一致返回 HTTP 409；无来源返回业务错误；站内有修改且未确认时在访问 GitHub 前返回
    HTTP 409 与 `code=repository_local_changes`。
  - 按原链接重新导入：根链接跟随默认分支，tree/blob 跟随原分支或标签，commit 链接固定。
  - 上游未变且无站内修改时不写库，返回 `{template,updated:false}`。
  - 否则通过普通保存事务与版本检查写入：保留模板 ID、令牌安装、分类、白名单、上下架、排序及顶层
    标题/说明；替换正文与引用文件，相同主文件路径沿用技能 ID，上游删除的文件同步删除。
  - 拉取、解析、校验或并发冲突失败时保留原副本，错误提示“站内技能保持不变”。
- `DELETE /api/prompt-center/admin/:id?version=N`：按版本加锁删除模板、白名单、令牌安装和渐进式
  记录/文件/分块，返回 `{id,uninstalled_tokens}`。版本冲突 HTTP 409；缺失或无效版本、已删除模板返回业务错误。
  删除后清理该模板 ID 的正文页缓存。SQLite 会复用最大主键，若不清理，同 ID、同版本、同技能 ID 的新模板
  会读到旧正文（回归测试在移除清理时复现）。
- 用途说明：模型层改为单条 16 KiB UTF-8 字节边界，导入器原样保存，网关目录分页至少返回一条。

## 安全与兼容性

- 只读取公开 GitHub，复用固定 API/原始文件主机、固定提交、禁止重定向、有限大小与期限的现有链路。
- 删除锁序：删除先锁模板行再删绑定；保存先锁令牌再锁模板；替换安装先锁令牌、读取绑定不加锁、再锁模板。
  删除不持有令牌锁，不形成环形等待。
- 更新与删除都是管理员显式操作，会影响已安装令牌的后续请求；进行中的请求按既有版本复核规则失败或完成。
- 回滚：新列为可空 TEXT，旧程序忽略该列；已删除的模板无法通过回滚恢复，需从数据库备份恢复。

## 验证结果

后端（Go 1.25.5 amd64，Windows 本地 SQLite）：

- 模型：来源保存/旧客户端保留/站内修改识别/公共摘要隐藏、非法来源拒绝、三种模板长说明与 16 KiB 边界、
  删除的版本冲突/卸载/文件清理/重复删除，以及 SQLite 主键复用下的缓存隔离。
- 服务：导入草稿携带来源（原红灯用例转绿）；更新保留站点设置与技能 ID、删除上游文件、未变化不写库、
  站内修改需确认且确认前不访问网络、拉取失败保留原副本、无来源拒绝；目录分页长说明前进。
- 控制器与路由：公共接口不含来源、管理员接口含来源、409 冲突码区分、删除参数校验与卸载数量；
  普通用户访问新管理路由返回 403，管理员可到达处理器。

  `go test ./model ./service ./controller ./router -count=1 -timeout=60s` 全部通过。
