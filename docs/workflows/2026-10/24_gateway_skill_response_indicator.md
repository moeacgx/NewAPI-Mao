# 网关云端 Skills 回复标识

## 目标与范围

Classic、Default 操练场在对应助手回复底部展示「网关云端 Skills」徽标及技能名称。
外部 Agent 无法由网关直接控制界面；按用户选择，在实际使用技能的文本回答末尾追加文字标识。
文字会进入客户端保存的聊天历史，也可能影响要求纯 JSON 或纯代码的正文，属于显式选择的行为。
本次只开发与本地验证，不自动部署、推送或发布。

## 数据与接口契约

- 标识依据本次正式生成前重新校验授权的实际已读技能；安装状态、目录发现、读取失败不能作为使用依据。
- 技能按模板 ID、技能 ID 和版本去重。跨组重试清除上一尝试的信息；不暴露正文、引用文件和私有工具结果。
- 响应头 `X-New-API-Gateway-Skills` 使用无填充 Base64URL 编码 UTF-8 JSON：
  `{version:1,total:1,skills:[{template_id:1,skill_id:"id",version:1,title:"代码审查"}],truncated:false}`。
  编码值最多 6 KiB，超过时保留可容纳的完整条目并设置 `truncated=true`，`total` 保留实际总数。
- 该头表示正式请求已装载的技能，不承诺最终生成成功；页面必须结合成功回复处理状态。
  不能接受上游同名响应头覆盖本地信息。CORS 暴露该头，便于外部客户端适配。
- 两套操练场请求发送 `X-New-API-Skills-Display: metadata`，以独立元数据显示徽标，避免正文和徽标重复。
  未指定时，外部 API 对有文本的成功助手回复追加 `☁ 网关云端 Skills · 技能名称`。
  纯工具调用、私有发现阶段、错误响应、中断或不支持的正文不伪造普通文本回复。
- 保留四类 HTTP 对话协议的 JSON/SSE 封装、工具参数、思考块、原始用量与结束语义。
  网关生成的标识不修改上游实际用量，不作为本次模型生成 Token 额外收费。
- 不更改数据库、模型身份、认证、装载白名单或现有计费规则。

## 页面与状态

双模板采用主题一致的云端技能图标和紧凑标签，长名称换行，暗色与手机可辨识。
标识绑定到本次助手消息，重新生成清除旧信息；没有技能信息时隐藏。
本地持久化和导出保留显示元数据，后续模型请求仅提取聊天正文，不能把徽标字段发给上游。
错误或格式不合法的响应头按无标识处理，不能影响正常聊天。

## 验证计划

后端验证四协议普通/流式成功回复、中文标题、实际读取去重、仅发现不显示、失败/重试隔离、
上游伪造头防护、CORS、纯工具调用与原用量保留。Go 测试使用 `-timeout=60s`。
前端验证头解析、消息归属、成功/失败、重新生成、请求正文隔离、持久化与导出、长名称及无标识状态。
执行受影响测试、Default 类型检查、双模板受影响静态检查与构建、文档格式和链接检查。

- 后端定向验证通过：技能响应头、JSON 尾标、metadata 模式、失败轮次清理、
  OpenAI Chat SSE、Claude 工具调用抑制、Responses SSE 序号及响应头伪造防护。
- 受影响 Go 包验证通过：`go test ./service ./controller ./middleware ./router -count=1 -timeout=60s`。
  测试输出中的数据库未命中、Redis 关闭和限流日志均为既有测试夹具日志；最终各包均通过。
- Default 受影响 Vitest 16 项通过，类型检查和 `build:check` 通过；Classic 兼容测试 4 项通过，
  生产构建通过。双模板的技能标识请求头、响应头解析、成功/失败状态和正文隔离已覆盖。
- 仅在本地工作树验证；未推送、未发布、未部署到 zzapi 或其他线上容器。
