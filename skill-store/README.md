# NewAPI-Mao 技能商店

这里存放仓库公开维护的原创文本技能，随应用构建成为内置商店快照。
管理员也可在线刷新本仓库 `custom-main` 分支中的同一目录，再将技能导入站点草稿、编辑和发布。
站点副本不会被商店更新覆盖，站点编辑也不会回写仓库。

`index.json` 包含条目 ID、标题、说明、分类提示、版本，以及按装载顺序排列的文件路径和 SHA256。
文件路径相对于本目录，必须以 `packages/` 开头，不能包含回退、绝对地址或链接。
一个文件为单技能，2 至 16 个文件为合集；只支持文本，不执行脚本或附件。

新增或更新时先编辑 Markdown，再更新目录中的版本和逐文件 SHA256。
标题和正文仍需满足站点的单项、合集总量限制。运行 `go test ./service -run SkillStore -timeout=60s`
验证内置目录与文件校验和。在线刷新需先将这些文件发布到目标分支，未发布时可继续使用内置快照。
